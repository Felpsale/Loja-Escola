Projeto acadêmico de front-end inspirado no universo de **Cyberpunk 2077** e no RPG de mesa **Cyberpunk RED**. A ideia foi transformar a base de uma loja virtual em um mercado clandestino de artefatos futuristas e invenções impossíveis, praticando estrutura semântica, estilização responsiva, manipulação do DOM e consumo de API.
